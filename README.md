# [Online Event Management Platform](https://guiv-event-management-web-app.vercel.app/)
## Overview
This application is an Event Management System built using the MERN (MongoDB, Express.js, React.js, Node.js) stack. It allows users to browse, register for events, and manage their bookings, while admins can manage event creation, edit details, and view participant data.

### Tech Stack
Frontend: React.js

Backend: Node.js with Express.js

Database: MongoDB (Atlas)

Authentication: JWT (JSON Web Token) for secure login

Role-based Access: Two roles — Admin and User

### User Roles
### *Admin* (existing test admin id: admin@gmail.com | password: admin)

Create events

Update event details

Delete events

View all bookings and user information

Manage users (assign roles)

### *User*

Register for events

View event details

Book events

View profile
